# The Day Spa Salon — demo storefront

Responsive static website made with HTML, CSS and vanilla JavaScript.

## Pages
- `index.html` — homepage and salon overview
- `catalogue.html` — product catalogue with category filters and sorting
- `product.html?id=...` — product detail page; product is selected by URL
- `basket.html` — editable basket, saved in browser localStorage
- `account.html` — responsive sign-in and account creation demonstration
- `support.html` — contact form and salon support information

## Open it
Unzip the folder, then open `index.html` in a modern browser. Google Fonts and product photography load from the internet. Basket contents are kept in that browser. Forms and checkout are demonstration interactions and do not submit to a live store or payment provider.

The product catalogue is representative sample content for the design and should be reconciled with the salon's live stock, prices and terms before publishing.
